# 📖 Overview

This repository contains all the **mandatory hands-on exercises** completed as part of the **Cognizant Digital Nurture 4.0 – Java Full Stack Engineering (Java FSE)** training program.

The objective of these hands-ons is to build a strong foundation in Java programming, backend development using Spring Boot, frontend development using React and Angular, database programming, software testing, version control, and microservices architecture.

Each module focuses on practical implementation, allowing learners to gain real-world experience through coding exercises and projects.
